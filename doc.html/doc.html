InferForge Go back

Documentation

CLI, InferForge beta, training, and API.

Install

powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
bash ./scripts/install.sh
pip install -e .

Commands

forge import ollama     Import local Ollama models
forge list              List registered models
forge train             Train / rebuild InferForge beta
forge chat              Open InferForge beta chat UI
forge run <model>       Chat with any model
run <model>             Shortcut for forge run
forge create <name>     Create a derived model
forge show <model>      Model details
forge pull <hf-id>      Pull from Hugging Face
forge embedd <model>    Embed weights into InferForge
forge serve             OpenAI-compatible API :11435
forge paths             Data / config locations
forge version           Version

InferForge beta

Own coding model (Ollama base + InferForge curriculum). Not labeled as the base model in chat.

forge train
forge chat
forge run inferforge-beta

Agent tools: create_file, edit_file, delete_file, read_file, list_dir, run_command

Train

forge train
forge train --base qwen2.5-coder:7b
forge train my-model --data examples.json --base llama3.1:8b
forge train --export-dataset coding.json

forge serve
