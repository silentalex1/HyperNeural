Install InferForge

Clone the repo, run the installer, then forge chat

Windows powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
macOS / Linux bash ./scripts/install.sh
pip pip install -e .

Quick start

$ forge import ollama
$ forge train
$ forge chat
$ forge list
$ forge serve
